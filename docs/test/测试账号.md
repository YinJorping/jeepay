# 测试账号

## 支付网关 API 凭证

| 字段 | 值 |
|------|-----|
| mchNo | MCH-TEST-001 |
| appId | APP-TEST-001 |
| appSecret | test_app_secret_abc123 |

## 三层关系

```
ISV-TEST-001 （服务商）
     └── MCH-TEST-001 （商户，通过 isv_no 关联）
            └── APP-TEST-001 （应用，通过 mch_no 关联，appSecret 用于签名）
```

## 写入方式

通过 SQL 直接插入（未通过运营平台 UI 创建）：

```sql
-- 服务商
INSERT INTO t_isv_info (isv_no, isv_name, isv_short_name, state, created_at, updated_at)
VALUES ('ISV-TEST-001', '测试服务商', '测试服务商', 1, NOW(), NOW());

-- 商户
INSERT INTO t_mch_info (mch_no, mch_name, mch_short_name, type, isv_no, state, created_at, updated_at)
VALUES ('MCH-TEST-001', '测试商户', '测试商户', 1, 'ISV-TEST-001', 1, NOW(), NOW());

-- 应用
INSERT INTO t_mch_app (app_id, app_name, mch_no, state, app_secret, created_at, updated_at)
VALUES ('APP-TEST-001', '测试应用', 'MCH-TEST-001', 1, 'test_app_secret_abc123', NOW(), NOW());
```
