# 环境搭建笔记

## 启动命令

```bash
# 编译后端（首次或代码变更后执行）
mvn clean package -DskipTests

# 启动 7 个容器（跳过 3 个前端 UI，不需要）
docker compose up -d --build mysql rocketmq-namesrv rocketmq-broker redis payment manager merchant
```
